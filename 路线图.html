线路 A
住宿登记线
随时触发
一个人也走

卡点说明 超过 24 小时：警告 + 可罚 2000 元以下，并影响后续居留许可

  • 触发：学生一到校（或一入住宿舍）就派人，不攒批、不等车
  • 带：护照原件 + 签证/入境章 + 住宿证明（宿舍证明，或租房合同 + 房东证件）
  • 一次带 1–3 人就能办；周末、节假日必须有人值班
  • 产出：《境外人员临时住宿登记表》原件或清晰照片 —— 后面办卡、开户、办居留许可都要用
线路 B
太谷城区线
每天下午成队
2–4 人一趟

顺序：先卡后行 银行卡必须留本人实名手机号，所以电话卡在前

中国移动营业厅（太谷骨科医院对面）
本人到场 · 人脸核验 · 不能代办
→
中国建设银行 太谷支行
护照 + 登记表 + 盖章在读证明 + 本人手机号
  • 前置条件：住宿登记已完成，材料齐全，才允许带出队
  • 银行柜台办外籍开户慢：先踩点问清「每天能办几个、要不要预约」，再按预约带人
  • 一趟办完登记：手机号 / 运营商 / 套餐 / 开户行 / 卡号后四位
线路 C
太原体检线
出市 · 攒够 4 人
或固定每周发车

当天去当天回 学校不安排车辆，志愿者全程带队点名

太谷出发（早晨，学生空腹）
→
山西国际旅行卫生保健中心（长风商务区 · 万象城东南约 750 米）· 体检
→
现场填邮寄单：收件人 = 老师 / 学校
  • 带：护照原件、2 寸照片、在校证明、体检费；早上空腹，避开周末
  • 出发前问清：体检项目、要不要预约、报告几天出、能否直接邮寄
  • 产出：体检报告邮寄单号进台账 → 报告到校后 第一时间交老师，不压在志愿者手里
每日机制（总调度盯这三件事）
  • 台账列阵：姓名 / 到达时间 / 登记完成 / 手机号 / 开户 / 体检日 / 报告单号
  • 收工对账：有没有谁到了还没做住宿登记
  • 成队规则：线路 B 每天下午；线路 C 满 4 人或每周固定日
红线
  • 护照原件不代管，志愿者只用复印件
  • 不代签、不代填假信息，本人到场核验
  • 不垫钱、不代收现金，费用当场问老师
  • 学生离校 / 去太原必须报备，去回都点名
