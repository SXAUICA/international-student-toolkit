# SXAU ICA · 留学生服务工具集

山西农业大学国际交流协会（ICA）志愿者团队，为在校留学生做的**离线可用、中英双语**的校园信息工具。

面向的真实场景：留学生陆续到校，语言不通、没有校园网账号、不知道去哪办事。整套东西都能直接双击打开、断网可用、可以微信发给学生。

## 怎么跑

没有构建、没有依赖、没有服务器。**双击 `留学生手册-网页demo.html` 就能打开。**

页面里没有任何外部资源（没有 CDN、没有 Google Fonts、没有外链图片），所以国内网络可用、断网可用、整个文件夹拷给别人也能用。

用浏览器打开后：

- 顶部按钮切换 **中英同屏 / 纯中文 / 纯英文** 三种模式（把手机递给中国店员时切「中文」）
- 地图上点数字看说明；搜索框支持中英文（输 `bank` 或 `银行` 都能定位到中国工商银行）
- 分类筛选：门 / 住 / 吃 / 服务 / 学 / 医 / 运动 / 试验场 / 牧站

## 地图数据约定（改数据前必读）

`校园地图节点.js` 的坐标系**沿用课设 `map_data.js` 的约定**：

```js
{ id: 1, name: "西门", en: "West Gate", cat: "gate", x: 29.2, y: 46.4 }
```

- `x`：横向百分比，从**左边**起算
- `y`：纵向百分比，从**底边**起算 ← 注意，不是从上边
- 前端渲染时要换算：`css_top = 100 - y`

分类 `cat` 取值：`gate` `medical` `shop` `sport` `dorm` `study` `farm` `utility` `other`

`inset: true` 表示该点位于底图左上角那张「牧站总平面图 1:2500」**插图**里，坐标已归到主图的牧站区域，不是它在校园里的真实位置。

## 已知问题 / 可以接着做的事

**数据层面**

1. **坐标是「文字标签的位置」，不是建筑中心**。199 个点都是按底图上印刷的文字位置提的，所以"点在标签上"是准的，但标签未必贴着建筑。要更准，需要有人对着原图逐个校正（用 `地图标注工具.html` 的「移动」模式拖动即可）。
2. **道路数据完全不存在**。课设的 `MAP_EDGES` 是建筑与建筑之间的抽象连接（权重 + 道路类型），没有几何形状，画不出路。要路网只能在底图上人工描：打开 `地图标注工具.html`，用「画路」沿路点几下即可，支持导出。
3. **留学生公寓到底是几号楼没确认**，地图上暂时标在 21#–23# 公寓一带并打了「待确认」。
4. **保卫处、外事处**在底图上没有标注，缺这两个点。
5. 底图右上角有校徽和标题栏占位，理想情况应换成不带标题栏的干净底图。

**功能层面**

- 地图目前是静态点位 + 筛选，没有做路径规划
- 手册还没有纸质版（建议做成 A5 骑马钉，8 页以内）
- 讲座 PPT、双语台账还没做

## 给接手的人

改文案不用碰代码：`留学生手册-网页demo.html` 里每一段都是 `<span class="zh">…</span><span class="en">…</span>` 的结构，改文字就行。

改地图点位有两个办法：

1. 直接编辑 `校园地图节点.js`（坐标按上面的约定）
2. 打开 `地图标注工具.html`，可视化拖动 / 增删 / 描路，导出后替换该文件

页面排版改动请保持**手机优先**和**零外部依赖**这两条——国内网络环境和学校网络都不适合引外链。

改动约定、地图数据怎么改、红线是什么，都写在 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 想参与

这个项目对所有人开放。不需要会写代码，能帮忙的事有很多：

| 你能做的 | 怎么做 |
|---|---|
| 核实地图点位 | 打开 `地图标注工具.html` 拖动修正，或直接开 issue 说哪个点错了 |
| 拍照补内容 | 食堂菜单、清真餐厅、办事窗口的材料清单——照片发过来就能用 |
| 翻译 | 现在英文是志愿者翻的，母语者看一眼会更好 |
| 实地验证 | 从西门走到留学生公寓走一遍，把沿途认得出的楼名记下来 |
| 写代码 | 看 [Issues](https://github.com/SXAUICA/international-student-toolkit/issues)，标了 `good first issue` 的适合上手 |

开 issue 有模板，选「地图点位纠错」最省事。
